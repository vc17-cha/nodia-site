# Site public de Nodia

Deux pages statiques, sans dépendance ni traçage : une page de présentation et
la politique de confidentialité exigée par les boutiques d'extensions.

- **Présentation** — <https://vc17-cha.github.io/nodia-site/>
- **Confidentialité** — <https://vc17-cha.github.io/nodia-site/confidentialite.html>

C'est cette seconde adresse qu'il faut déclarer au Chrome Web Store et à Edge
Add-ons.

Le code de l'extension vit dans un dépôt séparé et privé. Ce dépôt-ci n'existe
que pour rendre ces deux pages publiques.

## Mettre à jour

Toute modification de la politique doit être reportée depuis `PRIVACY.md` du
dépôt de l'extension, et la date en en-tête mise à jour. Les deux doivent rester
d'accord : c'est la version publiée ici qui fait foi auprès des boutiques.
