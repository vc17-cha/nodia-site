Politique de confidentialité

Dernière mise à jour : 22 septembre 2026 · Version 1.6.0

Nodia est une extension de navigateur qui aide un commercial à qualifier ses prospects sur LinkedIn. Elle a été conçue pour fonctionner sans serveur : vos données ne quittent pas votre ordinateur.

En résumé

QuestionRéponse
L'extension collecte-t-elle des données ?Uniquement celles que vous saisissez ou enregistrez vous-même.
Ces données sont-elles envoyées quelque part ?Non. Elles restent dans le stockage local de votre navigateur.
Y a-t-il des statistiques d'usage, de l'analytique, du traçage ?Non, aucun.
Des données sont-elles vendues ou partagées ?Non, jamais.
Y a-t-il un compte à créer ?Non.
Du code est-il téléchargé à distance ?Non. Tout le code est contenu dans l'extension.

Données traitées

Lorsque vous enregistrez un prospect, l'extension conserve localement :

  • le nom de l'entreprise affichée sur la page LinkedIn consultée ;
  • les données légales publiques renvoyées par l'API Recherche Entreprises (SIREN, SIRET, code NAF, adresse du siège, commune) ;
  • les informations de qualification que vous saisissez : contexte du besoin, timing, priorité, date de relance ;
  • le prénom et le nom du contact, si vous choisissez de les renseigner ;
  • l'adresse de la page LinkedIn consultée et la date d'enregistrement.

Lorsque vous lancez une recherche de décideur, l'extension conserve en plus un brouillon temporaire — l'entreprise en cours de prospection et sa qualification — afin de vous le proposer sur la page suivante. Ce brouillon reste local, expire au bout de deux heures, et disparaît dès que le prospect est enregistré ou que vous cliquez sur « Abandonner ».

L'extension ne lit ni vos messages, ni vos contacts, ni votre profil, ni aucune partie de LinkedIn autre que le nom d'entreprise affiché sur la page ouverte.

Où ces données sont stockées

Dans chrome.storage.local, l'espace de stockage local de votre navigateur, sur votre machine. Cet espace :

  • n'est accessible qu'à cette extension ;
  • n'est pas synchronisé entre vos appareils ;
  • est entièrement supprimé lorsque vous désinstallez l'extension.

Requêtes réseau sortantes

Nodia n'émet qu'un seul type de requête, et uniquement quand vous cliquez sur « Analyser l'entreprise » : 

GET https://recherche-entreprises.api.gouv.fr/search?q=<nom d'entreprise>

Cette API publique et gratuite est opérée par la Direction interministérielle du numérique (DINUM, gouvernement français). Seul le nom de l'entreprise est transmis — aucun identifiant, aucune donnée personnelle, aucune information sur vous ou sur votre navigation. Conditions de l'API : recherche-entreprises.api.gouv.fr/docs.

Aucune autre requête n'est émise vers aucun autre serveur, y compris ceux de l'auteur de l'extension.

Vos droits et vos moyens d'action

  • Consulter vos données : la fenêtre de l'extension liste vos derniers prospects.
  • Exporter : le bouton « Exporter vers Excel » produit un fichier CSV de l'intégralité de vos données.
  • Supprimer : le bouton « Réinitialiser » vide la liste. La désinstallation de l'extension efface tout.

Aucune de ces données n'étant transmise à l'auteur, il n'existe aucune copie ailleurs que sur votre machine — et donc aucune demande d'effacement à adresser à qui que ce soit.

Données sensibles

Nodia ne traite ni données de santé, ni données financières, ni données d'authentification, ni contenu de communications personnelles.

Modifications

Toute évolution de cette politique sera publiée sur cette page, avec mise à jour de la date en en-tête. Un changement affectant le traitement des données s'accompagnera d'une note dans les notes de version de l'extension.

Contact
